Production marketplace 2025 — 2026

Services marketplace platform

A production marketplace connecting customers and service providers through ordering, task management, real-time messaging and structured dispute resolution.

Overview

Osdire runs a services marketplace where customers order work from providers. I joined the product team as a full-stack developer on a large production codebase, building core features and making the platform more reliable and faster to load.

My role

Full-stack developer — features end to end, regression testing, refactoring and performance

Technology

LaravelVue.jsTypeScriptMySQLPHPUnitVitest

Development areas

  • ▹Real-time customer and provider messaging
  • ▹Resolution Centre and task workflows
  • ▹Automated regression coverage
  • ▹Core Web Vitals and media delivery improvements

Problem

Orders, conversations and disputes in one product

A marketplace lives or dies on trust between strangers: customers and providers need to agree on work, talk while it happens and resolve problems when it goes wrong — all inside a codebase that was already large and in production.

Responsibility

What I built and maintained

  • ●Features: order and task management, real-time messaging and the Resolution Centre for disputes, across Laravel, Vue.js and TypeScript
  • ●Quality: expanded automated regression coverage with PHPUnit and Vitest
  • ●Stability: refactored legacy components, resolved production issues and reduced technical debt
  • ●Collaboration: worked with product owners, designers and non-technical stakeholders to define and prioritise work

Engineering choices

Test the fragile parts; send less to the browser

  • ●Regression tests focused where bugs hide: search, sorting, timezone and daylight-saving handling, and media processing
  • ●Image delivery: responsive srcset generation, CloudFront-based media delivery, and lazy versus priority loading chosen per image
  • ●Full stack ownership: backend APIs and database design through to responsive front-end interfaces and production deployments

Delivered result

Shipped to a live platform

The messaging, task and dispute features shipped to production users. The image-delivery work contributed to improved Core Web Vitals and Lighthouse results for Largest Contentful Paint and Cumulative Layout Shift.

Evidence: the codebase and measurements belong to the employer and are not public, so this summary is based on my employment record rather than published figures.
