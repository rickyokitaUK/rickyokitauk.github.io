Software that ships
Government & enterprise systems 2016 — 2023

Identity & document systems for public services

A run of mission-critical systems at Linkpower: a facial-tracking API that auto-crops and straightens ID photos, a document-capture migration for Customs and Excise, OCR web services for Towngas and GovHK portals.

Overview

For seven years at Linkpower Technology I delivered and supported systems where mistakes are expensive: identity photos, customs documents, retail integrations and enterprise workflows. The work spanned new builds, migrations and long-term vendor support from development through production and disaster recovery.

My role

Software engineer — design, implementation, UAT → production → disaster recovery, vendor support

Problem

Systems that cannot quietly fail

Government and enterprise clients needed systems that integrate with scanners, OCR engines and existing back-office platforms, move through formal UAT, and keep running in production and disaster-recovery sites.

Responsibility

Selected deliveries

  • ●HKSAR Immigration Department: revived an intelligent passport face-crop application using a facial-tracking API (clmtrackr.js), with automatic cropping, orientation and resizing
  • ●Hong Kong Customs and Excise: completed a full document-capture system migration within a six-month deadline
  • ●Watsons: developed a Retek REST API for the online retail system with Java Spring and Hibernate, delivered within three months
  • ●Enterprise clients including CCBI and Towngas: led five to six IoT and CRUD application projects across C#, .NET, React, Vue.js and Laravel

Engineering choices

Integration first, then operations

  • ●Capture pipeline: DLL plugins for TeleForm, Docuflo, ABBYY OCR and Kodak scanners connected document hardware to back-office systems
  • ●Search: web development with an embedded Autonomy IDOL search engine for government-hosted services
  • ●Operations: full-cycle delivery from DEV and UAT to production and DR sites on Windows Server 2019 and MSSQL

Delivered result and evidence

Delivered on deadline — details stay confidential

The Customs migration was completed within its six-month deadline and the Watsons API within three months. Client systems, screenshots and data are confidential, so this case study is limited to the scope and responsibilities recorded in my employment history.
