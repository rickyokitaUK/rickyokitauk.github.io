公共服務的身份及文件系統

在 Linkpower 參與的一系列關鍵系統：自動裁切及校正證件相的臉部追蹤 API、海關文件擷取系統遷移，以及為煤氣公司和 GovHK 網站提供的 OCR 網絡服務。

概覽

我在 Linkpower Technology 工作了七年，交付及支援一些出錯代價很高的系統：證件相片、海關文件、零售系統整合和企業流程。工作包括新系統開發、系統遷移，以及由開發到正式環境和災難復原的長期支援。

我的角色

軟件工程師——設計、實作、UAT → 正式環境 → 災難復原、供應商支援

技術

C# / .NETJava SpringVB.NETJavaScriptMSSQLOCR

開發範疇

  • ▹臉部追蹤護照相裁切
  • ▹在限期內完成文件擷取系統遷移
  • ▹零售 REST API 整合
  • ▹正式環境、災難復原及 Windows Server 運作

問題

不能悄悄出錯的系統

政府和企業客戶需要能與掃描器、OCR 引擎和現有後勤系統整合的系統，這些系統要通過正式的 UAT，並在正式環境和災難復原站點持續運作。

職責

部分交付項目

  • ●香港入境事務處：以臉部追蹤 API（clmtrackr.js）重新啟用智能護照相裁切程式，自動裁切、校正方向和調整大小
  • ●香港海關：在六個月限期內完成整個文件擷取系統遷移
  • ●屈臣氏：以 Java Spring 和 Hibernate 為網上零售系統開發 Retek REST API，三個月內交付
  • ●建銀國際（CCBI）和煤氣公司等企業客戶：主導五至六個物聯網及 CRUD 應用項目，使用 C#、.NET、React、Vue.js 和 Laravel

工程取捨

先整合，再營運

  • ●擷取流程：為 TeleForm、Docuflo、ABBYY OCR 和 Kodak 掃描器開發 DLL 外掛，把文件硬件連接到後勤系統
  • ●搜尋：為政府託管的服務開發內嵌 Autonomy IDOL 搜尋引擎的網站
  • ●營運：在 Windows Server 2019 和 MSSQL 上，由開發、UAT 到正式環境和災難復原站點的完整交付

交付成果與證據

按期交付——細節保密

海關遷移在六個月限期內完成，屈臣氏 API 在三個月內交付。客戶系統、截圖和數據都屬保密，所以這份案例只限於我工作紀錄中的範圍和職責。
