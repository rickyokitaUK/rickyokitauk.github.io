生產級交易平台 2025 — 2026

服務交易平台

一個連接客戶與服務提供者的生產級交易平台，提供落單、任務管理、即時訊息和結構化的爭議處理。

概覽

Osdire 經營一個服務交易平台，客戶向服務提供者訂購工作。我以全端開發者身份加入產品團隊，在大型生產代碼庫中開發核心功能，並讓平台更可靠、載入更快。

我的角色

全端開發者——端到端功能、回歸測試、重構和效能

技術

LaravelVue.jsTypeScriptMySQLPHPUnitVitest

開發範疇

  • ▹客戶與服務提供者即時訊息
  • ▹Resolution Centre 及任務流程
  • ▹自動化回歸測試覆蓋
  • ▹Core Web Vitals 及媒體傳送改善

問題

訂單、對話和糾紛集中在同一個產品

交易平台成敗在於陌生人之間的信任：客戶和服務提供者要就工作達成協議、在進行期間溝通，出問題時能夠解決——而這一切都要在一個已經很龐大、正在運作的代碼庫中完成。

職責

我開發和維護的部分

  • ●功能：以 Laravel、Vue.js 和 TypeScript 開發訂單及任務管理、即時訊息，以及處理糾紛的 Resolution Centre
  • ●品質：以 PHPUnit 和 Vitest 擴大自動化回歸測試覆蓋
  • ●穩定性：重構舊組件、解決正式環境問題、減少技術債
  • ●協作：與產品負責人、設計師和非技術持份者一起定義需求和排列優先次序

工程取捨

測試最脆弱的部分；少送一點東西給瀏覽器

  • ●回歸測試集中在容易藏 bug 的地方：搜尋、排序、時區和夏令時間處理，以及媒體處理
  • ●圖片傳送：自動生成響應式 srcset、經 CloudFront 傳送媒體，並按每張圖片決定延遲或優先載入
  • ●全端負責：由後端 API、資料庫設計，到響應式前端介面和正式部署

交付成果

已在正式平台上線

訊息、任務和糾紛處理功能已推出給正式用戶使用。圖片傳送的改善有助提升最大內容繪製（LCP）和累計版面位移（CLS）的 Core Web Vitals 及 Lighthouse 結果。
