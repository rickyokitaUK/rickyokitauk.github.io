在 Unity 製作點擊移動：讓角色沿滑鼠路徑移動

以 Raycast 取得地面座標，製作點擊移動的角色控制；附滑鼠選取原理解說，以及整理過、適用於 Unity 6 的程式碼。

筆者從小喜歡 Ragnarok Online 這類 2D／3D 遊戲：在地上點一下，角色就會自己走過去。這個技術背後的原理叫滑鼠選取（mouse picking），我在 2007 年的畢業專題研究過，最近亦在一個 Unity 小遊戲中再次用上。

滑鼠選取的原理

螢幕就像一扇通往 3D 世界的窗。每一個像素，都對應一條由攝影機出發、穿過該像素的射線。玩家點擊時，我們建立這條射線，找出它最先擊中的表面（這裡是地面），再把擊中點設為角色的目的地。

滑鼠選取有兩種經典做法：射線投射（ray casting），準確但運算稍多；以及讀取深度緩衝，速度快，但準確度受深度值精度限制。由於運算只在玩家點擊時發生，射線投射的成本幾乎可以忽略，所以點擊移動通常都採用它。

實作步驟

  1. 按下（或按住）滑鼠時，用 Camera.ScreenPointToRay 把滑鼠位置轉換成射線。
  2. 只對地面圖層做 Raycast，避免道具、角色或其他碰撞體「搶走」點擊。
  3. 把擊中點存為目標，並保留角色自身的高度，避免角色下沉或浮起。
  4. 每個物理步驟都向目標移動。
  5. 進入細小的停止距離後，停下並清除目標。

程式碼

以下是原型中控制器的整理版本。和我最初的版本相比，它在 Update 讀取輸入、在 FixedUpdate 移動剛體，用明確的 hasTarget 旗標代替與當前位置比較，並以正規化方向而不是 Lerp 來控制移動。

using UnityEngine;

[RequireComponent(typeof(Rigidbody))]
public class ClickToMove : MonoBehaviour
{
    [SerializeField] float moveSpeed = 4f;
    [SerializeField] float stopDistance = 0.1f;
    [SerializeField] LayerMask groundLayer; // only the walkable ground

    Rigidbody rb;
    Camera cam;
    Vector3 target;
    bool hasTarget;

    void Awake()
    {
        rb = GetComponent<Rigidbody>();
        cam = Camera.main;
    }

    void Update()
    {
        // Pick a destination on click, and keep updating it while the button is held.
        if (!Input.GetMouseButton(0)) return;
        Ray ray = cam.ScreenPointToRay(Input.mousePosition);
        if (Physics.Raycast(ray, out RaycastHit hit, Mathf.Infinity, groundLayer))
        {
            target = new Vector3(hit.point.x, transform.position.y, hit.point.z);
            hasTarget = true;
            Debug.DrawRay(ray.origin, ray.direction * hit.distance, Color.yellow, 1f);
        }
    }

    void FixedUpdate()
    {
        if (!hasTarget) return;
        Vector3 toTarget = target - rb.position;
        toTarget.y = 0f;
        if (toTarget.magnitude <= stopDistance)
        {
            // Arrived: stop on the ground plane and clear the target.
            rb.linearVelocity = new Vector3(0f, rb.linearVelocity.y, 0f);
            hasTarget = false;
            return;
        }
        Vector3 dir = toTarget.normalized;
        rb.linearVelocity = new Vector3(dir.x * moveSpeed, rb.linearVelocity.y, dir.z * moveSpeed);
        rb.MoveRotation(Quaternion.LookRotation(dir));
    }
}

版本備註：Unity 6 把 Rigidbody.velocity 改名為 linearVelocity；Unity 2022 或更早版本請使用 velocity。如果項目使用新版 Input System，請改用 Mouse.current.leftButton 和 Mouse.current.position 讀取點擊。

我踩過的坑

  • 點到牆或 NPC：在 Raycast 只檢測地面圖層之前，角色會走到錯誤位置。
  • 下沉或浮起：直接用擊中點的 y 值會令角色陷入斜坡；保留角色自身的高度就能避免。
  • 到達目的地時抖動：沒有停止距離，角色會衝過頭再折返。
  • 遊戲狀態仍然重要：原型中玩家昏倒時會忽略移動。輸入應該和其他系統遵守同一套規則。
  • 障礙物：這個做法只會走直線。正式關卡應烘焙 NavMesh，並呼叫 NavMeshAgent.SetDestination(hit.point)，讓角色繞過牆壁。

差不多二十年前，同一個選取原理亦驅動了我 2007 年 DirectX RPG 原型中的點擊移動。
