淺談網絡科技與網頁製作

2010 年的網頁製作筆記：Google 的崛起、Photoshop 切片，以及以 div 和 CSS 排版的早期做法。
Read in English →

舊文存檔。 作為我創作歷程的一部分保留下來——當中的工具和參考反映的是撰寫時的情況。

今天跟表弟討論過 Google。
記得六、七年前 Yahoo 仍是主流……但轉眼間，

Google 每月的搜尋次數已突破「31 億」。

除此之外，還有其他很強大的專有工具：
Google Map
Google Calendar
Google 翻譯
……
現在還自製 Nexus One 力撼 iPhone。
真感慨這短短十年內的網絡科技發展一日千里，
亦令我想起這就是一個活生生的全球化（Globalization）例子。

網頁製作紀事錄（1）

說起設計網頁，我並不是這方面的專家，
不過都略知有關 HTML5 vs Flash、Firefox vs IE 等等的資訊。

回正題，今日想介紹兩種製作「靜態」網頁排版的方法：
1）利用 Photoshop 直接輸出網頁格式，再用 Dreamweaver 直接更改；
2）利用 Photoshop 局部製作網頁配件，再用 Dreamweaver 修改原始檔（要知道 div 及 CSS 的用法）。
經過多次做網頁的經驗，現在多數人傾向用 <div> 跟 CSS 這兩個東西來做網頁排版！

1）Photoshop 切片工具（Slice Tool）

做網頁一定離不開繪圖。在 Photoshop 設計好後，利用切片工具就可以根據你自訂的規劃，分割出按鈕、文字框架等等。轉換成 HTML 檔後匯入 Dreamweaver，就可以更改了！
例子：任天堂 Game Boy Advance 的遊戲網頁，正正是用這個方法排版的！

其實用 Photoshop 轉換成 HTML 是有跡可尋的：打開網頁的原始檔，就不難發現「spacer.gif」的蹤影了！

參考：PSD to HTML Slicing Tutorials（Internet Archive 存檔）

2）<div> 與 CSS

另一個方法是用 div。div 是 HTML 的一個標籤，用來包住網頁上的任何物件（文字、圖片……），你亦可以把它想像為 Photoshop 的 Group 功能。

最強大的是：div 可以讓你把物件放到任何地方，不用受傳統 HTML 表格的 td、tr 所限制。例如：

<div style="position:absolute; top:200px; left:100px;"><img src="images/pic.jpg" /></div>

在這個 div 中，我把圖片固定在左上方，跟網頁的邊界保持少許距離。如果以座標方式去想，left 是 x 座標，top 是 y 座標，而圖片由 (100, 200) 開始貼上。

至於甚麼是 CSS？它其實是一個超方便的樣式表，可以改變文字、格式、顏色等。用法就是給一個樣式名稱，再定義它的特性。用上述的例子，今次把原始碼改成：

<div id="mystyle"><img src="images/pic.jpg" /></div>

再到 CSS 檔或頁面中加入：

#mystyle {
    position: absolute;
    top: 200px;
    left: 100px;
}

心水清的朋友就會明白，這個名為「mystyle」的東西，內容其實跟之前的 style="…" 沒有分別，這就是所謂的 CSS 了！但點解要咁做呢？因為樣式只寫一次，就可以套用到很多個元素，日後修改亦只需改一個地方。

存檔說明（2026）：這篇 2010 年的筆記保留了當時的想法，只修復了排版、失效連結和被刪去的程式碼。今天已經不會用 absolute 定位來做整頁排版，Flexbox 和 CSS Grid 取代了表格和 spacer.gif；不過「內容與樣式分開」這個原則，到今天仍然適用。
