Unity – 以 Blend Tree 製作八方向 2D 角色

以 Unity 的 2D Freeform Cartesian Blend Tree，為 Ragnarok Online 風格的 2D 角色設定八個方向的行走動畫。
Read in English →
  • Animation
  • Unity
  • 中文

製作 Ragnarok Online 風格的 2D 角色，需要八個方向的動畫。與其在程式中用一大堆 if 判斷角色面向，不如交給 Unity 的 Blend Tree：把角色在 x、z 平面上的移動方向傳入 Animator，它就會自動選出對應方向的動畫。

1. 準備八個方向的動畫

每個方向製作一段行走動畫（sprite 序列），依指南針命名：moveN、moveNE、moveE、moveSE、moveS、moveSW、moveW、moveNW。統一命名，之後在 Animator 中設定和除錯都會輕鬆很多。

2. 建立 Blend Tree

  1. 在 Animator 中新增 Blend Tree，Blend Type 設為 2D Freeform Cartesian。
  2. 新增兩個 Float 參數 MoveX 和 MoveY，並指定為 Blend Tree 的參數。
  3. 加入八段動畫，按方向填上座標：
動畫MoveXMoveY
moveN01
moveNE0.750.75
moveE10
moveSE0.75−0.75
moveS0−1
moveSW−0.75−0.75
moveW−10
moveNW−0.750.75

斜向的值用 0.75 而不是 1，是為了讓八個點大致落在同一個圓上，令每個方向佔的範圍更平均。

3. 由程式傳入方向

角色在 3D 場景的地面上移動，所以把速度的 x 和 z 分量傳給 MoveX 和 MoveY：

// Feed the blend tree from the character's movement on the ground plane (x, z).
Vector3 v = rb.linearVelocity;
Vector2 move = new Vector2(v.x, v.z);
float speed = move.magnitude;
animator.SetFloat("Speed", speed);

// Only update the facing while moving, so an idle character keeps looking the way it last walked.
if (speed > 0.05f)
{
    move /= speed;
    animator.SetFloat("MoveX", move.x);
    animator.SetFloat("MoveY", move.y);
}

只在移動時更新方向很重要，否則角色停下的一刻，參數會歸零，面向亦會跳回預設方向。

為何 sprite 動畫也能「混合」？

3D 骨骼動畫可以在兩段動畫之間插值，但 sprite 是一張張圖片，無法真正混合。Animator 遇到這類不能插值的屬性時，會採用權重最高的那段動畫，所以 Blend Tree 實際上就是「選出最接近的方向」，正好是八方向角色需要的效果。

補充：Unity 亦有 2D Simple Directional 類型，專為「每個方向一段動畫」而設，用在這個情況同樣合適；如果之後要在同一方向加入跑步動畫，則可以改用 2D Freeform Directional。
