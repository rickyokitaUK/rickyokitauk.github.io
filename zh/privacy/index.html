私隱政策

最後更新：2026 年 10 月 7 日

這是 Rick Chow 的個人作品集網站。我把資料收集減至最少：本網站沒有帳戶、沒有電子報、沒有廣告，亦不會出售或為推廣目的分享任何資料。

本中文版本僅供參考；如與英文版本有任何差異，以英文版本為準。

負責人

本網站的資料控制者為 Rick Chow（英國利物浦）。如有查詢或要求，請電郵 rickchow.uk@gmail.com。

分析工具（只在你同意後使用）

我使用 Google Analytics 4 了解訪客閱讀了哪些頁面、如何找到本網站，以便改進網站。首次瀏覽時，橫額會請你作出選擇：

  • 接受——Google Analytics 可設定 cookie（_ga 及 _ga_36YZ71HCKD，最長保留 2 年）以辨認重複到訪。它會記錄瀏覽的頁面、大約位置（根據 IP 地址推算的國家／城市）、裝置和瀏覽器類型，以及你如何到達本網站（例如搜尋器或連結）。
  • 拒絕（或未作選擇）——不會儲存任何分析 cookie。Google 仍可能收到不含 cookie 的匿名訊號（Google Consent Mode），這些訊號無法識別你或你的裝置。

廣告功能、Google 信號和個人化廣告均已關閉。分析數據會保留 14 個月，之後自動刪除。處理的法律依據是你的同意；你可隨時透過 （頁尾亦有此連結）改變選擇。

Google LLC 作為我的服務供應商處理這些數據，並可能根據英國國際數據轉移附錄／英美數據橋把數據轉移至美國。請參閱 Google 私隱權政策及 Google 如何使用使用其服務的網站的數據。

Microsoft Clarity

如你選擇接受，我亦會使用 Microsoft Clarity 了解頁面的使用情況——點擊和捲動熱圖，以及頁面互動錄影——以便改善令人困惑的版面。Clarity 會遮蓋你輸入的文字；如你拒絕，Clarity 完全不會載入。它可設定 cookie（_clck、_clsk、CLID、MUID，最長保留 1 年）。Microsoft Corporation 作為我的服務供應商處理這些數據，詳見 Microsoft 私隱聲明。

語言及顯示偏好

本網站提供英文和繁體中文版本。首次瀏覽時，系統會在你的瀏覽器內檢查時區和語言設定，以建議顯示語言；這些資料不會傳送給我或任何第三方。如你使用語言切換或淺色／深色模式切換，你的選擇會儲存在瀏覽器的 local storage 中，以便下次記住。你可隨時在瀏覽器設定中清除。

聯絡我

聯絡表格不會在本網站傳送或儲存任何資料——它只會開啟你自己的電郵程式並預先填好訊息。如你電郵給我，我只會使用你的名字、電郵地址和訊息作回覆之用，並在不再需要時刪除有關通訊（一般在 2 年內）。

內嵌影片

項目影片存放於 YouTube，但只會在你按下播放時才載入，並使用 YouTube 的私隱強化模式（youtube-nocookie.com）。影片開始播放後，即適用 YouTube 本身的 私隱權政策。

網站寄存

本網站是寄存於 GitHub Pages 的靜態網站。GitHub 可能為保安和穩定性記錄訪客的 IP 地址；請參閱 GitHub 私隱聲明。 字型和圖片均由本網站直接提供，並非來自第三方字型服務。

你的權利
